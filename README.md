# Don Bong — Modular Platform v3.0

## Описание

Don Bong – это современная модульная платформа для магазина аксессуаров и научно‑просветительского контента.  
Проект построен на чистом HTML/CSS/JS с React‑компонентами и полностью статичен, что позволяет развернуть его на любом хостинге статики (Cloudflare Pages, Netlify, Vercel).  
Данные хранятся в Google Sheets, а уведомления о заказах отправляются в Telegram.

## Функциональность

- **Магазин** – каталог товаров с фильтрацией, сортировкой, пагинацией, корзиной и избранным.
- **Научные статьи** – библиотека, разделы о перколяции и гигиене.
- **AI-консультант** – чат-бот, помогающий выбрать товар.
- **Сменные темы** – тёмная, светлая, синяя, золотая.
- **Админ-панель** – управление товарами, заказами, отзывами, настройками (защищена паролем).
- **Google Sheets** – централизованное хранение данных.
- **Telegram уведомления** – о новых заказах.

## Развёртывание на Cloudflare Pages

1. **Создайте репозиторий на GitHub** и загрузите все файлы.
2. **Войдите в Cloudflare** → Pages → Create a project → Connect to Git → выберите репозиторий.
3. **Настройте сборку:**
   - Build command: оставить пустым
   - Build output directory: оставить пустым
4. Нажмите **Save and Deploy**. Через минуту сайт будет доступен по ссылке `https://donbong.pages.dev`.
5. (Опционально) Добавьте свой домен в разделе **Custom domains**.

## Настройка Google Sheets (бэкенд)

1. Создайте копию [этой таблицы](https://docs.google.com/spreadsheets/d/1RL2LMNYI5wOXnreYr9ya4wG8d-GQ_WCLll4lSo5BCUk/edit?usp=sharing) или используйте свою.
2. В меню **Расширения → Apps Script** вставьте код из файла `backend.gs`.
3. Опубликуйте скрипт: **Deploy → New deployment → Web app → Execute as: me → Who has access: Anyone**.
4. Скопируйте полученный URL – это ваш `API_URL`.
5. В файле `utils.js` замените значение `window.API_URL` на этот URL (или установите через админ-панель после первого входа).

## Настройка Telegram бота

1. Создайте бота через [@BotFather](https://t.me/botfather) и получите токен.
2. Узнайте свой `chat_id` (напишите боту `/start`, затем запросите `https://api.telegram.org/bot<token>/getUpdates`).
3. В админ-панели (или в `utils.js`) укажите `TG_TOKEN` и `TG_CHAT_ID`.

## Локальный запуск

Просто откройте файл `index.html` в браузере. Все зависимости подключены через CDN.

## Структура файлов

- `index.html` – главная страница (скелет)
- `core.css` – стили, темы, анимации
- `utils.js` – утилиты, API, localStorage
- `navigation.js` – роутинг, меню, темы
- `shop.js` – магазин, корзина, избранное
- `react-components.js` – React-компоненты
- `admin.js` – админ-панель
- `backend.gs` – скрипт для Google Sheets

## Админ-панель

Пароль по умолчанию: `DonBong2025`  
После входа вы сможете:
- Редактировать товары (название, цена, наличие)
- Управлять заказами (изменять статус)
- Удалять отзывы
- Менять настройки API и Telegram
